## 1. ОБЩЕЕ ОПИСАНИЕ СИСТЕМЫ

### 1.1 Назначение
Система представляет собой **Telegram Mini App** для демонстрации объектов недвижимости (новостроек) с полной административной панелью управления.

### 1.2 Целевая аудитория
- **Агенты по недвижимости** — владельцы системы
- **Клиенты агентов** — пользователи каталога (покупатели квартир)

### 1.3 Основные компоненты
1. **Клиентское приложение** (Mini App в Telegram)
2. **Административная панель** (веб-интерфейс)
3. **Бэкенд** (Google Apps Script)
4. **База данных** (Google Sheets)
5. **Хранилище файлов** (Google Drive)

## 3. КЛИЕНТСКОЕ ПРИЛОЖЕНИЕ

### 3.1 Описание
Telegram Mini App, которое открывается внутри Telegram. Предназначено для просмотра каталога объектов и отправки заявок.

### 3.2 Основной функционал

#### 3.2.1 Приветственный экран
- Логотип и название компании
- Фоновое изображение
- Кнопка "НАЧАТЬ ПОДБОР"
- Настраивается через `client-config.json` (branding section)

#### 3.2.2 Каталог объектов
**Список объектов:**
- Карточка объекта: фото, название, адрес, цена, район, метро
- Статус: "Активен" / "Скрыт"
- Фильтры:
  - 💰 Цена (до 5/10/20/50/100 млн ₽)
  - 📍 Районы (чекбоксы)
  - 🚇 Метро (чекбоксы)
  - 🚪 Комнаты (чекбоксы)

**Просмотр объекта:**
- Галерея фото (карусель)
- Основная информация: цена, адрес, метро, класс, отделка, срок сдачи
- Описание
- Преимущества (список)
- Планировки (фото или текст)
- Кнопка "Заказать консультацию"

**Карта:**
- Отображение объектов на карте (Leaflet.js)
- Маркеры с ценой
- Клик по маркеру → открытие объекта

#### 3.2.3 Форма заявки
Поля:
- Имя (обязательно)
- Телефон (маска +7)
- Telegram (необязательно, латиницей)

**Отправка:**
- Данные сохраняются в лист `Leads`
- Отправляется уведомление в Telegram боту-почтальону
- Статус по умолчанию: "new" (Новая)

#### 3.2.4 Меню
- 🏠 Каталог
- 👤 Обо мне (динамическая страница)
- 📞 Контакты (данные агента из `AgentData`)
- ⚙️ Админ-панель (только для владельца)

## 5. СВЯЗЬ АДМИНКИ С КЛИЕНТСКИМ ПРИЛОЖЕНИЕМ

### 5.1 Общая конфигурация

**Файл:** `client-config.json`

```json
{
  "client": {
    "projectId": "demo-miniapp-realty",
    "scriptUrl": "https://script.google.com/.../exec",
    "secretKey": "Secret_new_int_111"
  },
  "sheets": {
    "agentData": "https://docs.google.com/.../pub?gid=...&output=csv",
    "pages": "https://docs.google.com/.../pub?gid=...&output=csv"
  }
}
```

### 5.2 Общие источники данных

| Данные | Источник | Где используется |
|--------|----------|------------------|
| **Объекты** | Google Apps Script (`Listings`) | Клиент: каталог<br>Админка: CRUD |
| **Заявки** | Google Apps Script (`Leads`) | Клиент: создание<br>Админка: просмотр, статусы |
| **Профиль** | Google Apps Script (`AgentData`) | Клиент: контакты<br>Админка: редактирование |
| **Страницы** | Google Apps Script (`Pages`) | Клиент: "Обо мне"<br>Админка: редактирование |

### 5.3 Синхронизация данных

#### 5.3.1 Объекты
**Создание/Обновление (Админка):**
1. Admin → `apiCall('create'/'update', params)`
2. Apps Script → валидация PIN
3. Запись в `Listings`
4. Ответ: `{success: true, id: '...'}`

**Чтение (Клиент):**
1. Client → `fetch(scriptUrl)`
2. Apps Script → чтение `Listings`
3. Фильтрация: только `active=TRUE`
4. Ответ: массив объектов

**Синхронизация:**
- Мгновенная (через Google Sheets)
- Клиент кэширует данные при загрузке
- Админка обновляет список после сохранения

#### 5.3.2 Заявки
**Создание (Клиент):**
1. Client → `fetch(scriptUrl, {action: 'save_lead', data: {...}})`
2. Apps Script → запись в `Leads`
3. Отправка уведомления в Telegram
4. Ответ: `{success: true, id: 'lead-...'}`

**Чтение (Админка):**
1. Admin → `apiCall('get_leads', {})`
2. Apps Script → валидация PIN
3. Чтение `Leads`
4. Ответ: массив заявок

**Обновление статуса (Админка):**
1. Admin → `apiCall('update_lead_status', {id, status})`
2. Apps Script → валидация PIN
3. Обновление поля `status` в `Leads`
4. Ответ: `{success: true}`

#### 5.3.3 Фото
**Загрузка (Админка):**
1. Выбор файла → Base64
2. `apiCall('upload_image', {image, fileName})`
3. Apps Script → декодирование Base64
4. Создание Blob → сохранение в Drive
5. Установка доступа: "Anyone with link can view"
6. Получение URL: `https://lh3.googleusercontent.com/d/FILE_ID`
7. `apiCall('get_last_file_url')` → получение URL
8. Сохранение URL в объекте/профиле

**Отображение (Клиент и Админка):**
- Прямая загрузка с Google Drive CDN
-Fallback на placeholder при ошибке

### 5.4 PIN-защита

**Генерация хеша:**
```javascript
function hashPin(pin) {
  var rawHash = Utilities.computeDigest(
    Utilities.DigestAlgorithm.SHA_256,
    pin
  );
  return rawHash.map(function(byte) {
    var v = (byte < 0) ? 256 + byte : byte;
    return ('0' + v.toString(16)).slice(-2);
  }).join('');
}
```

**Проверка:**
1. Admin отправляет `pin` в каждом запросе
2. Apps Script вычисляет хеш полученного PIN
3. Сравнение с `Config!B1`
4. Если не совпадает → ошибка "Неверный PIN"

**Защищённые операции:**
- ✅ `create`, `update`, `delete` (объекты)
- ✅ `get_leads`, `update_lead_status`
- ✅ `get_agent_profile`, `update_agent_profile`
- ✅ `get_pages`, `update_page`

**Открытые операции:**
- ✅ `save_lead` (заявка от клиента)
- ✅ Чтение объектов (без скрытых)

1. Открыть Apps Script
2. Запустить функцию `setupTelegram()` с параметрами:

3. Или вручную в Properties Service

function checkRateLimit(ip) {
  var key = 'rate_' + ip;
  var count = cache.get(key);
 
  if (!count) {
    cache.put(key, '1', 3600); // 1 запрос в час
    return true;
  }
 
  if (parseInt(count) > 10) {
    return false; // Слишком много запросов
  }
 
  cache.put(key, String(parseInt(count) + 1), 3600);
  return true;
}
